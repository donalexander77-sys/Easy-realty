EASY REALTY APP

Open index.html in a browser to preview the app.

For normal use on a phone:
1. Upload all files in this folder to a web host.
2. Visit the web address in Chrome or Safari.
3. Choose "Add to Home Screen" to make it behave like an app.

Current features:
- Call and text Don
- Buyer lead form
- Seller lead form
- Home value request
- FSBO-to-buyer lead section
- Seller net sheet calculator
- Tallahassee relocation section
- Property tax review request
- FAA Part 107 drone services
- Offline-capable service worker
- Installable PWA manifest

Important:
Lead forms save the information on the visitor's own device and then provide a button to text the request to Don.
For a production app, connect forms to email, a CRM, Google Sheets, or a secure database.
